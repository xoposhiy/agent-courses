DEFINITIONS

TASK // single test with defined inputs and success criteria

TRIAL // attempt at a task

BENCHMARK \[EVALUATION SUITE\] // task set measuring specific capabilities

VERIFIER \[GRADER\] // logic that scores agent’s performance

TRAJECTORY \[TRACE\] \[TRANSCRIPT\] // complete record of a trial

EVALUATION HARNESS // infrastructure that runs evals end-to-end

AGENT HARNESS //system that enables a model to act as an agent
