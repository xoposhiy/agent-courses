# Gaps and limits

[Course index](README.md)

PDF Markdown is extracted text. Diagrams, tables, and equations may need the original file. Large video binaries, private services, unpublished materials, dependencies, and model weights are outside this archive.

All five advertised module PDFs were recovered from the forum's public CDN originals. The original short attachment URLs return 404, but every recovered PDF has the SHA-1 encoded in its advertised short link. Initial failed responses are retained separately for provenance.

The official lecture-notes post warns that the slide PDFs are not maintained and can omit topics or contain errors. Lecture videos are updated separately. Preserve this warning when using the slides to design teaching material.

PDF Markdown is full page-by-page text extraction. The original PDFs preserve diagrams, tables, and exact mathematical notation.

Only public sources were fetched; no course enrollment, payment, account changes, or downloaded code execution was performed.

All 28 public video transcripts were captured from anonymous server-rendered lesson HTML, including timed captions where supplied. No video binaries were downloaded.

The remaining eight readings and six ungraded notebook labs require login in the anonymous browser. Five graded notebook labs and five quizzes are marked Pro-only in the public catalog. These are recorded as access gaps, not converted from generic help or sign-in text.

No separate official public repository for this specific November 2026 course was found in targeted title/provider searches. The older 'Evaluating AI Agents' course was not substituted.

[Anonymous browser access evidence](raw/access/anonymous-reading-snapshot.yml) records the reading viewer's login requirement. The isolated browser session was closed after inspection.
