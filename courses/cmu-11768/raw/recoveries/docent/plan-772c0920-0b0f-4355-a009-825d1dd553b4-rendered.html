Terminal-Bench reward on tasks with no timeouts

How do the models compare on tasks where neither model ever times out?

Behavior

GPT-5.1-codex has a lower overall pass rate than GPT-5-codex on Terminal-Bench (27% vs 40%), and it hits the agent time limit in half its runs. Earlier analysis suggested that most of GPT-5.1-codex's extra failures come from running out of time before delivering. Here we remove timeouts from the picture to ask whether GPT-5.1-codex is still worse when time limits are not a factor.

Measurement

We keep only tasks where no run by either model hit AgentTimeoutError, including runs that were never scored, and where both models have at least one scored rollout. A pivot table shows, for each remaining task, each model's number of scored rollouts and mean reward (reward is 1 if hidden tests pass, else 0). We then compute each model's macro-average reward: the mean over tasks of the per-task mean reward, so every task counts equally regardless of how many rollouts it has.
