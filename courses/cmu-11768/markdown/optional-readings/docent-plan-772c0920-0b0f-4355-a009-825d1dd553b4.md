## Step 1: How do the models compare on tasks where neither model ever times out?

## Behavior
GPT-5.1-codex has a lower overall pass rate than GPT-5-codex on Terminal-Bench (27% vs 40%), and it hits the agent time limit in half its runs. Earlier analysis suggested that most of GPT-5.1-codex's extra failures come from running out of time before delivering. Here we remove timeouts from the picture to ask whether GPT-5.1-codex is still worse when time limits are not a factor.

## Measurement
We keep only tasks where no run by either model hit AgentTimeoutError, including runs that were never scored, and where both models have at least one scored rollout. A pivot table shows, for each remaining task, each model's number of scored rollouts and mean reward (reward is 1 if hidden tests pass, else 0). We then compute each model's macro-average reward: the mean over tasks of the per-task mean reward, so every task counts equally regardless of how many rollouts it has.

## Step 2: Pivot: rollouts and mean reward per model per task, on tasks with no timeouts

### DQL query

```sql
WITH runs AS (
  SELECT metadata_json->>'task' AS task,
    metadata_json->'agent'->>'model_name' AS model,
    CAST(metadata_json->'scores'->>'reward' AS DOUBLE PRECISION) AS reward,
    CASE WHEN metadata_json->>'exception' = 'AgentTimeoutError' THEN 1 ELSE 0 END AS timed_out
  FROM agent_runs
),
no_timeout_tasks AS (
  SELECT task FROM runs GROUP BY task
  HAVING SUM(timed_out) = 0
    AND SUM(CASE WHEN model = 'openai/gpt-5.1-codex' AND reward IS NOT NULL THEN 1 ELSE 0 END) > 0
    AND SUM(CASE WHEN model = 'openai/gpt-5-codex' AND reward IS NOT NULL THEN 1 ELSE 0 END) > 0
)

SELECT r.task AS task,
  SUM(CASE WHEN r.model = 'openai/gpt-5.1-codex' AND r.reward IS NOT NULL THEN 1 ELSE 0 END) AS gpt_5_1_codex_rollouts,
  ROUND(CAST(AVG(CASE WHEN r.model = 'openai/gpt-5.1-codex' THEN r.reward END) AS NUMERIC), 3) AS gpt_5_1_codex_mean_reward,
  SUM(CASE WHEN r.model = 'openai/gpt-5-codex' AND r.reward IS NOT NULL THEN 1 ELSE 0 END) AS gpt_5_codex_rollouts,
  ROUND(CAST(AVG(CASE WHEN r.model = 'openai/gpt-5-codex' THEN r.reward END) AS NUMERIC), 3) AS gpt_5_codex_mean_reward,
  SUM(r.timed_out) AS timeouts_all_runs
FROM runs r JOIN no_timeout_tasks t ON t.task = r.task
GROUP BY r.task
ORDER BY r.task
```

## Step 3: Macro-average reward per model on tasks with no timeouts

### DQL query

```sql
WITH runs AS (
  SELECT metadata_json->>'task' AS task,
    metadata_json->'agent'->>'model_name' AS model,
    CAST(metadata_json->'scores'->>'reward' AS DOUBLE PRECISION) AS reward,
    CASE WHEN metadata_json->>'exception' = 'AgentTimeoutError' THEN 1 ELSE 0 END AS timed_out
  FROM agent_runs
),
no_timeout_tasks AS (
  SELECT task FROM runs GROUP BY task
  HAVING SUM(timed_out) = 0
    AND SUM(CASE WHEN model = 'openai/gpt-5.1-codex' AND reward IS NOT NULL THEN 1 ELSE 0 END) > 0
    AND SUM(CASE WHEN model = 'openai/gpt-5-codex' AND reward IS NOT NULL THEN 1 ELSE 0 END) > 0
)
,
per_task AS (
  SELECT r.model, r.task, AVG(r.reward) AS task_mean_reward, COUNT(r.reward) AS rollouts
  FROM runs r JOIN no_timeout_tasks t ON t.task = r.task
  WHERE r.reward IS NOT NULL
  GROUP BY r.model, r.task
)
SELECT model, COUNT(task) AS tasks, SUM(rollouts) AS scored_rollouts,
  ROUND(CAST(AVG(task_mean_reward) AS NUMERIC), 3) AS macro_avg_reward
FROM per_task GROUP BY model ORDER BY model
```
