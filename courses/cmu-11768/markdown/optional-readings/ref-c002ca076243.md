**Summary of changes**

Add a concise Use Cases tutorial for configuring a model, three GitHub credentials, three scoped agent profiles, and four independent automations through Agent Canvas. Include a 36-second recording and reusable screenshots captured from the actual UI setup against neubig/airbnb-clone.

The guide matches the current four extension manifests and documents the minimum fine-grained PAT permissions. It explicitly targets a preview build because profile-scoped automation execution and Docker conversation runtimes must ship before the standard Canvas installer supports the walkthrough.

**Live validation**

All four automations were created and enabled through the recorded UI. Six issues were triaged and six developers ran concurrently in Docker. The resulting [airbnb-clone PR #87](https://github.com/neubig/airbnb-clone/pull/87) through [PR #92](https://github.com/neubig/airbnb-clone/pull/92) were each tested and given a readable exact-head review by an agent using the non-push reviewer token. The profile-free host watchdog reused the developer token, updated stale branches, waited for fresh exact-head evidence, and merged all six PRs. The final cycle also survived a graceful Canvas restart by resuming the two interrupted reviewer conversations.

The page rendered locally, all tutorial images and the GIF load, and the use-case automation synchronization check passes. Generated LLM text changes are limited to the updated tutorial section.

Closes [#796](https://github.com/OpenHands/docs/issues/796).
