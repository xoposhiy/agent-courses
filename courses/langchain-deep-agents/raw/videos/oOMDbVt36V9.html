Tool Decorator

Now we're at a fun part, defining a tool with a tool decorator. The tool decorator from the LangChain library is super simple. You write a regular Python function, and the decorator turns it into something the model can call. LangChain also ships some ready-made tools for common tasks, such as Tavily search results for web search, so you don't have to write everything from scratch.

But let's take a look at what it actually looks like

So this is some code, and this is a diagram demonstrating the different parts of the code. First, we have the actual decorator itself

Just by adding @tool above your function, LangChain registers it as a tool. Super easy. Then come the name and schema

These come directly from the function signature. The function name becomes the tool name and the arguments and their types become the schema.

So def get_stock_price gives the model a tool called get_stock_price

And expects a string called ticker. That's what gets sent to the LLM so it knows to call it. And finally, the most important part, the description. This is your docstring, and it's the only signal the model has for deciding when to reach for this tool versus any other. You want to write this clearly and specifically and describe what the tool does and when to use it.
