Messages, Threads and Checkpointers Lab

This lab is about how the agent remembers things across multiple calls. Three concepts make that work: messages, threads, and checkpointers

This new import is MemorySaver from LangGraph checkpoint memory. Create Deep Agent looks the same as before, but with one new addition

MemorySaver assigned to checkpointer. A checkpointer is what gives the agent somewhere to save thread state between calls, and without it, each invoke starts fresh with no memory of what came before. MemorySaver stores that state in memory, which is fine for local development

Two thread configurations. A thread is an ongoing conversation identified by a thread ID

Pass the same thread ID to continue an existing conversation and pass a different one to start a separate conversation with its own history. Here we have thread A and thread B

Thread A, turn one

The user tells the agent their favorite color is blue

And we pass this so the checkpointer knows which thread to save this to.

Thread A, turn two. Same question and same thread. The agent receives the new message

But the checkpointer also loads the saved history from turn one, so the model sees the full conversation, the original message
