As agents grow more capable, tasks span more steps, sessions run longer, and tool results pile up. Token counts climb steadily towards the model's limit and left unchecked, a long-running agent eventually stalls. Deep Agents handles this with two complementary mechanisms. On the left, you can see summarization. It watches the context fill up and compacts old messages into a summary before the model ever sees them. On the right, we have offloading. It intercepts individual inputs that are too large before they even enter context and saves them to the file system, and it leaves a pointer in their place.

These work on different problems. Summarization deals with gradual accumulation across many turns, and offloading deals with singular large spikes
