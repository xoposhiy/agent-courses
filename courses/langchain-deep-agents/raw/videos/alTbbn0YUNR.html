Sub-Agents

Long-running agents need coordination. A big task can span many steps, tool calls, files, and intermediate results. Without an explicit way to track the plan and isolate specialized work, the main agent can drift or overload its context.

Deep Agents gives the main agent two coordination tools to address this: planning and delegation. Planning keeps the main agent organized, and it's opt-in. You turn it on with to-do list middleware

Now delegation moves specialized or context-heavy work out of the main agent's context entirely.

A capable model can draft a solid plan for a multi-step job. The hard part is follow through. As the conversation grows and the agent juggles tool calls and intermediate results, it tends to drift, losing track of what's done and what isn't.

Deep Agents addresses this with an opt-in write-to-dos tool

Just add the todo list middleware to the agent's middleware list, and the model gets a tool for writing out its plan as a structured list

It updates each item's status as it works: pending, in progress

or complete it

That list is saved in the agent state, and it persists across turns when you use the same thread with a checkpointer, which is the same thread pattern introduced earlier in the course on a long task, the agent always has an explicit up-to-date plan to check against instead of trying to hold the whole thing in its head.
