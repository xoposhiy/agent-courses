Recursive Language Models (RLMs)

Deep Agents implements a documented technique called the recursive language model, or RLM.

Introduced by these MIT researchers Now their core insight is that instead of a model treating a long context as one monolithic input, to split it into pieces, call each piece, and combine the results, recursing on any piece that's still too big to handle directly

So step one is the context splits into call A and call B, each handling half

Then both results feed into a third call, C, which combines them.

If half is still too big to handle in one call, that call recurses the same way, splitting into A1 and A2.

A1 and A2 are small enough to answer directly now, so they combine into call A3

A3's result feeds back up into call C and the loop closes. And the recursion bottoms out. It doesn't split forever

Deep agent's dynamic subagents use that same divide and conquer technique but dispatch full agents rather than recursing on the same model call. The team's more precise term for that

is recursive agents. RLM is the popular shorthand that you'll see used for the pattern generally. Now, the MIT paper reports RLMs handling inputs up to two orders of magnitude beyond a model's context window, with median gains on GPT-5 ranging from thirteen percent versus Claude Code to one hundred thirty percent versus Code Act with subcalls across four long context tasks.
