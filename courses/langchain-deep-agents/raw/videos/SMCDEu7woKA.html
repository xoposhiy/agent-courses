MCP

MCP stands for Model Context Protocol. It's an open protocol that standardizes how applications expose tools and context to LLMs. Instead of writing a custom integration for every service, any MCP-aware client connects to any MCP server using the same interface.

Now, before MCP, you'd write a separate integration for every service you wanted the agent to call. MCP replaces that with a single protocol. Any MCP-aware client connects to any MCP server, and the server handles all of the service specific details. MCP servers can expose three primitives: tools, resources, and prompts. This course focuses on tools. get_tools retrieves them as BaseTool objects you can pass directly to your agent. Resources and prompts exist in the spec but need separate client calls

Now, this is the key integration point. LangChain MCP adapters wraps each server tool as a standard base tool. The agency's MCP tools identically to locally defined tools. Results come back as tool messages in the conversation history exactly the same as any other tool call
