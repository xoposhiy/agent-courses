What is transport?
the layer that carries messages between your agent and the MCP server

Your Agent
calls a tool

Transport
stdio / HTTP

MCP Server
runs the tool


Transport is set once in .mcp.json.
Your agent code stays identical regardless of which type is used.
The next slides explain what each type is and when you would use it.

stdio: standard input and output
every command-line program already has these


stdin
The program's input stream.
Another process writes to it
to send a message.


stdout
The program's output stream.
The program writes its response
here for others to read.


Think of it like two programs passing notes through a pipe.
Program A writes a line to Program B's stdin.
Program B processes it and writes a reply to stdout.
No network, no URLs, no ports; just two processes on the same machine talking over text streams.

HTTP: the protocol that powers the web
ask a question, get an answer, connection closes


Client
sends a request
e.g. your browser


GET / POST


response body


Server
processes request
sends response


Connection closes after each exchange.
HTTP is stateless: the server treats each request as independent.
There is no memory of previous requests unless the client sends context.

(function(){

  prev.addEventListener('click',function(){if(cur>0)goTo(cur-1);});
